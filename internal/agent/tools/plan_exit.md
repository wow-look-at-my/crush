Ask the user to approve your implementation plan and leave plan mode.

This tool is only available while plan mode is active. Use it when you have finished researching and are ready to implement:

- Write the complete plan in the `plan` parameter, formatted as concise markdown: what you will change, the files involved, and any notable decisions or tradeoffs.
- The user is shown the plan and asked to approve it.
- If the user approves, plan mode ends, the editing tools become available, and you should implement the plan.
- If the user rejects the plan, you stay in plan mode. Refine the plan based on their feedback before asking again.

Do not call this tool before the plan is complete, and never call it just to ask a clarifying question.
